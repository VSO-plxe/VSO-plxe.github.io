# VSO-plxe — Динамическое портфолио

Добро пожаловать в репозиторий моего личного портфолио! Это не просто статическая HTML-страница. Это полностью динамическое, управляемое данными одностраничное приложение (Single Page Application), которое автоматически синхронизируется с моим профилем GitHub.

### 🔗 **[Смотреть вживую: VSO-plxe.github.io](https://vso-plxe.github.io)**

## 🚀 Функционал

Этот сайт был создан с нуля, чтобы продемонстрировать мои проекты современным и интерактивным способом.

* **🌐 Полная интернационализация (i18n):**
    * Автоматическое определение языка браузера (PL, EN, DE, RU).
    * Ручной переключатель языков с сохранением выбора в `localStorage`.
    * Весь текст на странице загружается динамически из внешних `.xml` файлов.

* **🤖 Интеграция с GitHub API (REST):**
    * **Динамический профиль:** Страница автоматически загружает мой аватар, биографию и количество подписчиков/подписок.
    * **Автоматический список репозиториев:** Портфолио загружает 30 моих последних обновленных репозиториев, отфильтровывая форки.

* **🌗 Переключатель темы (Светлая/Темная):**
    * Автоматическое определение системных предпочтений (`prefers-color-scheme`).
    * Ручной переключатель ☀️/🌙, сохраняющий выбор пользователя.
    * Иконки SVG в футере динамически меняют цвет (с белого на черный) с помощью CSS-фильтров.

* **⚡ Интерактивный пользовательский интерфейс (UI):**
    * **Живой поиск:** Фильтрует репозитории в реальном времени по мере ввода текста.
    * **Фильтры по языкам:** Автоматически генерирует кнопки фильтров на основе языков, найденных в загруженных репозиториях (например, "JavaScript", "Python").
    * **Загрузка README в модальном окне:** Клик по карточке проекта открывает модальное окно, которое загружает, парсит (`marked.js`) и отображает файл `README.md` из этого репозитория, не покидая страницы.

* **✨ Современный дизайн и UX:**
    * **"Skeleton Loaders" (Каркасы загрузки):** Вместо скучного текста "Загрузка..." отображаются мерцающие каркасы карточек, улучшая воспринимаемую производительность.
    * **Анимации "Fade-in":** Карточки проектов плавно появляются при прокрутке, используя `Intersection Observer API`.
    * **Дизайн "Glassmorphism":** Полупрозрачные, размытые фоны для современного вида.
    * **Плавный анимированный фон:** Многоцветный, анимированный градиент на CSS.
    * Полная адаптивность (RWD) для мобильных устройств.

## 🛠️ Стек технологий

Этот проект был намеренно создан **без использования фреймворков** (таких как React или Vue), чтобы продемонстрировать глубокое понимание основ веба.

* **Фронтенд:** Чистый HTML5, CSS3 и JavaScript (ES6+).
* **Дизайн:**
    * CSS Variables (для динамических тем).
    * CSS Flexbox & Grid (для адаптивной верстки).
    * CSS Animations & Transitions.
* **Логика приложения (JavaScript):**
    * **Async/Await** с **Fetch API** для обработки запросов к GitHub API и загрузки XML-файлов.
    * **DOMParser** для парсинга файлов локализации `.xml`.
    * **Intersection Observer API** для анимаций при прокрутке.
    * **localStorage** для запоминания предпочтений пользователя (язык, тема).
* **Внешние библиотеки:**
    * **[Marked.js](https://marked.js.org/):** Для мгновенного преобразования Markdown -> HTML в модальном окне.
* **Хостинг:**
    * **GitHub Pages**
